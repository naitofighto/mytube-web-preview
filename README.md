# MyTube Web Preview

Public **demo-only** interactive TV preview. No private Android source or YouTube account data is included.

- Cinematic Home, D-pad and virtual remote, collapsible left navigation, demo search, sample player.
- Demo images are stored locally under assets and are not real YouTube thumbnails.
- Public GitHub Pages hosting: https://naitofighto.github.io/mytube-web-preview/
- Private Android source lives separately under naitofighto/MyTube.

Pages uses `main` branch root. Do not put credentials, account data, production API URLs or private project files here.
